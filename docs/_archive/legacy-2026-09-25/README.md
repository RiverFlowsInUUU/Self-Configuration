## 为什么一件都不能搬

1. **读数判据锁路径**：`skill/tests/check_doc_readings.py`（冻结闸门文件）的 LIVE 清单按路径钉住
   `docs/注意事项.md`、`docs/规则集与来源.md`、`docs/跨内核差异对照.md`、`surge/docs/11-分流版设计.md`、
   两侧 `docs/08-审计读数.md`、两份 `DetailsReadme` 等 —— 搬走 ⇒ 判据"命中 0 处即判负"假红，
   而修判据属于冻结文件改动，不获批。
2. **历史链接锁路径**：`CHANGELOG.md`（只追加）、`docs/体检报告.md`、`docs/日志旧版原文.md`、
   `skill/reference/*/public-repo.md` 内含指向各专题旧文档的相对链接，`check_links.py` 全树扫链接 ——
   搬迁必然要求改这些不该改的文件，否则闸门红。
3. **门面锁目录形态**：根 `README.md`（用户明令不可修改）描述了"各内核 `docs/` 下一套编号专题文档"的结构。

三条约束优先级都高于"物理归档"这一组织偏好，故采纳**横幅冻结 + 映射表**方案：
文档留在原路径保全部历史与链接，横幅声明"已归档冻结、以手册为准"，去向查手册 99 章映射表。
