# 注意事项

> 使用前值得先看一遍的几条。订阅地址见 [`README`](../README.md)。

## 通用

| 项目 | 说明 |
|:----:|:-----|
| 🧩 **节点与订阅都得自己填** | 本仓库是**脱敏模板**：不含任何真实节点、订阅 token、凭据。懒人版自己填节点；分流版还需填订阅地址。不填则默认出口是断的——**所有走代理的流量都不通** |
| 🧭 **先选内核，再选分工** | 四份配置是「2 内核 × 2 分工」：`lazy`（至简，一个出口）与 `routing_v3`（按应用 + 按地区）。**各选一份用，不要叠加** |
| 📄 **每份都有带注释版与 `.min` 版** | 内容一致、只差注释。**改配置改带注释那份，再把改动同步到 `.min`** ——Surge 侧阶段 3 的架构检查会逐字比对两份的 DNS 段 |
| 🔄 **规则集刷新必须显式** | 全部远程规则集带 24 小时刷新。缺此字段时规则集可能只在首次下载，**上游新收录的域名会一直命不中** |
| 🔐 **不要把真实节点提交回来** | 公开模板。本地用随意，push 前先过占位符与凭据扫描 |
| 🧱 **本仓自包含** | 配置、图标、脚本与全部详解都部署在本仓，**不引用任何前身仓的地址**（它们可能转为私有）。需要外部参照时只指向内核官方文档；唯一的第三方依赖是社区规则集与图标来源，见 [`规则集与来源.md`](规则集与来源.md) |
| 🧪 **全部本地完成，刻意不挂 CI** | 改完在仓库根目录跑 `bash skill/tests/surge/run.sh` 与 `bash skill/tests/egern/run.sh`。环境要 **Python 3**，Egern 侧脚本还需 **PyYAML**（Windows 的 Git Bash 不自带，需自行安装）。**没跑成不等于跑绿** —— 命令与环境要求见 [`../skill/reference/surge/checker.md`](../skill/reference/surge/checker.md) |
| ⚠️ **「审计全绿」不等于「配置可用」** | 脚本只覆盖**静态可判定**的部分。拦截效果、误杀、节点可用性必须实测——这是 Egern 侧连续 5 次「脚本全绿、实测仍有问题」换来的结论 |

## Surge 侧

| 项目 | 说明 |
|:----:|:-----|
| ✈️ **分流版的 `Airport` 组** | `policy-path=<订阅 URL>`，token 为占位符。不填则只能靠 `[Proxy]` 的本机节点（地区组按节点名关键词筛选，也能用） |
| 🌏 **地区组可能为空** | 靠 `policy-regex-filter` 匹配节点名里的地区关键词。没筛到节点时 Surge **不会**拒绝加载，但指向它的规则会断流。导入后到面板确认哪几个组是空的 |
| 🔁 **改地区关键词要改两处** | `Other Regions` 的负向断言把另外 6 个地区组的关键词抄了一遍。改完立刻跑 `python skill/scripts/surge/audit_region_filters.py surge/profiles/routing_v3.conf` |
| 🚫 **`pre-matching` 策略不能写组** | 必须是字面量 `REJECT` 族，写成策略组会导致 **Surge 拒绝加载整份配置** |

## Egern 侧

| 项目 | 说明 |
|:----:|:-----|
| 🧩 **`lazy` 的 `Proxy` 必须填** | 它没有订阅槽位，`Proxy` 空着就所有走代理的流量都不通（其余版本填订阅即可） |
| ✈️ **分流版填 1 处订阅槽位** | 单一隐藏组 `Airport`（`routing_v2.4` 起把 A/B 合并为单入口） |
| 📜 **保留全部历代版本** | `profiles/` 下 `routing_v1` → `routing_v3` 共 8 版 ×2，逐版头部写明「为什么改」。推荐版是 `routing_v3`，历代见 `egern/docs/07` |
| 🔒 **`proxy_nameservers` 一设就跳过 `forward`** | 这是硬覆盖。设了它之后，写在 `forward` 里的节点域名规则就是**死代码**（Egern 坑 18） |
| 🧷 **不要用 YAML dump 重写 profile** | 含数千字符的超长单行（如 CA 证书 base64），dump 会丢注释、改格式。按行读入 + 断言「全文恰好命中 1 行」 |

## 移植改动时

两内核**分组已完全对齐（26/26 同名同序）**，分流版规则 24 条逐位对应，但**懒人版并不同构**，
且有若干内核级不可套用约束（`pre-matching`、`proxy_nameservers`、内置 `LAN`/`SYSTEM`）。
动手前读 [`跨内核差异对照.md`](跨内核差异对照.md)。
