# 图标与许可

## 图标

两内核的分组图标**原本是两份逐字节相同的拷贝**（实测 `diff -rq` 无差异），合并后只保留根级
[`icons/`](../icons/) 一份，26 个 png 同时服务 `surge/profiles/` 与 `egern/profiles/`，
共 618 处引用已改指新地址。

图标整合自以下项目，已存入本仓库，**配置中不跨项目引用任何外部图标地址**：

- [RiverFlowsInUUU/Rule](https://github.com/RiverFlowsInUUU/Rule)
- [jnlaoshu/MySelf](https://github.com/jnlaoshu/MySelf)
- [Koolson/Qure](https://github.com/Koolson/Qure)

清单：`AdBlock` `Airport` `Auto` `Final` `GitHub` `Google` `HongKong` `Japan` `Korea` `Microsoft`
`Nfcloud` `Proxy` `Singapore` `Spotify` `Taiwan` `Telegram` `Twitter` `UnitedStates` `WeChat`
